# Frontend Performance Testing - Lighthouse Task | Mentoring

## What should be done
*
Goal
Automate frontend performance testing of the Performance Testing Essentials application using Lighthouse with Puppeteer.

## Prerequisites
Deploy the Performance Testing Essentials training application locally using Docker by following the instructions in the repository (https://git.epam.com/epm-perf/performance-testing-essentials).

## Description
Create a Lighthouse script using Puppeteer that automates the following user flow:

Open the application.
Navigate to the "Tables" tab.
Open first table product card (click on a table).
Add the table to the cart (click "Add to Cart" button).
Open the cart.
Click "Place an order."
Fill in all required fields and click "Place order."
Run the Lighthouse test using your script and generate a Lighthouse report.

## Expected Output
Lighthouse test script.
Lighthouse test report.
